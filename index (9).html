What your notes app knows about you, even when your notes are encrypted

End-to-end encryption protects your note content. It does not protect the metadata your notes generate. Here is a field-by-field breakdown of the metadata collected by Standard Notes, Notesnook, Cryptee, and Joplin, and what it reveals.

D David
January 2026
Updated October 2026
~17 min read
Share
The common assumption when using an end-to-end encrypted notes app is that the service cannot see what you write. That is true. But every note you create, modify, or delete still leaves a trail of metadata your notes app can see clearly. That trail includes timestamps, file sizes, sync patterns, structural relationships, and in Joplin's case, GPS coordinates.[1] This analysis covers it field by field across four of the most privacy-focused notes apps available. They are also apps I personally use. Sources include official documentation, published privacy policies, sync API specifications, and open-source code repositories.

How to read the tables

Each cell answers one question. What can the company that runs the sync server learn from this?

  • VisibleThe company can read it.
  • Partly visibleThe company can read part of it, or work it out from what it does see.
  • EncryptedIt's stored on the server, but only your devices can read it.
  • Device onlyIt stays on your device and never syncs.
  • Not collectedThe app doesn't record it.
  • Not disclosedThe company doesn't say, and its server code isn't public.

Each row also says what that detail reveals about you, and each table ends with what it means in practice.

Joplin's column assumes you turned on its encryption, which is off by default, and that you sync through Joplin Cloud. With encryption off, the company can read everything in that column. If you sync to a server or folder you control, no company sees any of it.[2][3]

Any server knows when an upload reaches it. The tables cover what each app stores or reveals beyond that.

Timestamps

Timestamps are the metadata that matters most operationally. Again, they do not reveal what you wrote, but they do reveal when, how often, and for how long. We have seen in investigations that this is enough to piece together a network.

Note Content Fields

This is where all four products perform equally well. It is also what allows them to market end-to-end encryption. The title, body, tags, and folder names are encrypted in every product when E2EE is properly active. The server holds ciphertext and cannot read any of it.[2][11][16][17]

Revision history is one of the easiest metadata risks to overlook. But remember that every saved version carries its own timestamp. Together they create a detailed editing timeline that persists on the server independently of the note's content.

What this means Notesnook keeps past versions on your device only. Joplin syncs them to your server and keeps them for 90 days. You can shorten that or turn note history off under Settings, then Note History.[15]

Per-Product Summary

Standard Notes

BESTMost transparent documentation. The sync API spec is publicly available and explicit about every stored field.[12]

BESTPrivate username mode orphans all timestamps from a real identity. The data still exists, but it is linked to a meaningless hash, not a person.[27]

PROIP addresses stay out of long-term logs. Standard Notes says its firewall holds them for up to five minutes to stop abuse.[4]

WARNSaved versions are the biggest note-level risk. Its published server code saves a version when you return to a note after a break. The break is at least a day on the free plan, or five minutes on paid plans. Those versions stay until you delete the note. Your plan only decides how far back you can see them.[9]

WARNEach change records which login session made it, so the server can tell which of your devices edited a note.[9]

WARNSync token progression acts as a proxy clock that reveals editing frequency independently of timestamps.[9]

WARNDaily email backup, an opt-in feature on paid plans, creates a second metadata trail at your email provider. Timing, volume, and recipient are visible to them even if content is encrypted.[20]

Notesnook

BESTThe least detail per note. Its server keeps each item's ID, size, and type, and the time it last synced. Created and edited times, notebooks, and tags stay encrypted.[6]

PROVersion history never leaves your device.[18]

PROPer-note sync toggle. A note kept local-only reaches the server only as an encrypted deletion marker.[11]

WARNItem types are not hidden. Its server files every item by type, so it can count your notes, notebooks, and tags.[6]

WARNTimestamps are tied to your email address at registration. There is no private username option, so sync times are always attributable to an identifiable account.[26]

CONDevice fingerprint metadata makes sync events more attributable than any other product here. Notesnook collects device IDs, OS type, and IP address in its own systems, the only app here that does all three.[26]

Cryptee

PRONo email needed. You can sign up with only a username.[5]

WARNIts version IDs are save times. Each one is the time of a document's last save, to the microsecond. Cryptee's own app turns it back into the "last saved" date it shows you.[8]

WARNOld versions aren't addressed. Its privacy policy doesn't say whether earlier versions are kept, only that encrypted backups last up to 90 days.[5]

WARNFolders, sizes, and file types are stored. The server knows which folder each document is in, how big it is, and what type of file it is. It also counts the documents in each folder.[5][8]

WARNGhost Folders let you hide a folder so you can deny it exists if someone forces you to open your account. But the server still knows the overall structure.[28]

WARNIP addresses and browser details are kept for 180 days to detect abuse.[5]

Joplin

PROYou choose the server. Joplin can sync through Nextcloud or WebDAV on a server you run, or through a plain folder you keep in sync yourself. That way no company has to hold any of this.[3]

WARNNote history syncs. Past versions go to your sync server with their save times and stay 90 days by default. You can shorten that or turn note history off.[19]

WARNStructure stays visible. Even with encryption on, the server sees which notebook each note is in, which notes share a tag, and when each note last changed.[7][10]

CONLocation is saved by default. The desktop app gets it from your IP address through an outside service without asking. The lookup also tells that service your IP address. Phones ask for permission first. It sits in the note itself, not a server log, so it travels with every export regardless of encryption state.[21][22]

CONsource_url field. Web-clipped notes embed the origin URL in note properties. With E2EE off, this syncs in plaintext.

CONsource_application field. Every note records which Joplin client created it. Device-type fingerprinting at the per-note level.

Final Ranking, Least to Most Revealing

This counts what each app's server learns about your notes, and whether it can tie that to you.

1
Cryptee
Cryptee keeps one timestamp per document, the time of its last save. It keeps no GPS or source fields. It needs no email, so nothing it keeps is tied to your name. Its server does know which folder each document is in, how big it is, and what type of file it is. There are two caveats. The backend is closed source, and Cryptee hasn't published a third-party audit. So these claims rest on its privacy policy and its open-source app. It also keeps IP addresses for 180 days.[5][29][30]
2
Joplin (E2EE on + geolocation disabled + note history off)
With all three settings, the server can't read your notes, when you created them, or what type your attachments are. It still sees when each note last changed, which notebook it's in, and which notes share a tag. You can also sync to a server you run, which keeps all of that away from any company. If any of the three conditions is not met, Joplin becomes the worst of the four. The gap between best and worst configuration is larger here than in any other product.
3
Standard Notes (private username mode)
Its server keeps the most dated history of the four. That includes creation and edit times on every note, the login session behind each change, and saved versions. But private username mode orphans all of it from a real identity. And Standard Notes says it keeps IP addresses out of long-term logs. Timestamps linked to a hash with no associated PII are far less actionable than timestamps linked to an email address. It is also the most transparent of the four about what is actually stored.

Proton bought Standard Notes in 2024.[31] Its founder announced he had left Proton in July 2025.[32] That December, Standard Notes said it remains a separate product with dedicated engineers.[33]
4
Notesnook
Notesnook's server sees the least about each note. It sees only when the note last synced, what kind of item it is, and how big it is. Its version history never leaves your device. But it requires an email address, so all of that is tied to a real account. Its privacy policy also lists IP addresses and device identifiers among what it collects. Once that account-level data is included, it reveals the most about who you are.
